# NUT-30: BLS12-381 Keyset

`optional`

---

This document defines the use of BLS12-381 cryptography for keysets in the Cashu protocol, enabling smaller proofs and facilitating multi-signature schemes and batch verification.

## Protocol Changes

### 1. Keyset Format (v3)

BLS12-381 keysets, referred to as `v3` keysets, utilize the BLS12-381 curve.

### 2. Blinding

`v3` keysets use multiplicative blinding:
- `Alice` computes blinded message: `B_ = Y * r`
- `Bob` signs: `C_ = k * B_`
- `Alice` unblinds: `C = C_ * inv(r)` (where `inv(r)` is the modular inverse of `r` in the scalar field of the curve).

### 3. Verification

`v3` keysets use BLS pairing verification instead of DLEQ proofs.
The mint verifies the signature by checking:
`e(C, G2) == e(Y, K2)`

Where:
- `e` is the pairing function.
- `G2` is the generator of the G2 group.
- `K2` is the mint's public key in the G2 group.

### 4. Keyset ID Generation

For BLS12-381 keysets, the keyset ID `id` MUST be generated using a format that utilizes the `02` prefix to distinguish it from `secp256k1` keysets.
